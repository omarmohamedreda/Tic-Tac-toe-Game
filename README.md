# Simple Tic-Tac-Toe Game 🎮

Welcome to the **Simple Tic-Tac-Toe Game**! This project is a straightforward implementation of the classic game, built using **C#** with a **Windows Forms Application** for the user interface.

---

## Features

- 👥 **Two-Player Mode:**
  - Play locally with another player.

- 🎨 **User-Friendly Interface:**
  - Built with Windows Forms for a smooth and interactive experience.

- 🔄 **Reset Option:**
  - Restart the game anytime.

---

## Technologies Used

- 💻 **Programming Language:** C#
- 🖥️ **Framework:** .NET Framework
- 🖌️ **UI Technology:** Windows Forms Application

---

## Getting Started

### Prerequisites

- 🖥️ A Windows operating system
- 🛠️ Visual Studio (or any compatible IDE that supports Windows Forms development)

### Running the Game

1. **Clone the Repository:**
   ```bash
   git clone https://github.com/omarmohamedreda/Simple-Tic-Tac-Toe.git
   ```

2. **Open the Project:**
   - Open the `.sln` file in Visual Studio.

3. **Build and Run:**
   - Click on the **Start** button in Visual Studio to build and run the application.

4. 🎉 Enjoy playing Tic-Tac-Toe!
